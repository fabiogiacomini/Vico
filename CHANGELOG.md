# Changelog

## 0.1.0 — local prototype — 2026-10-26

- Product name confirmed as Vico; interface confirmed as English only.
- Shared Android/iOS implementation started with Expo/React Native.
- Local outings, bounded GPX import, gap-preserving geometry, meeting point versions, foreground positioning and route-pack checks.
- Optional attributed area forecasts with source time and consent, honest crowd states and inactive source registry.
- Per-outing encrypted native storage and key deletion with durable recovery and anti-resurrection tombstones.
- Memory-only browser preview and synthetic practice route.
- MIT license adopted for Vico's original code following the owner's decision. Third-party licenses and secure group protocol compatibility remain under review.
- Public GitHub source repository established under MIT, with private vulnerability reporting enabled. Connected chat, physical-phone feasibility and a public mobile release remain pending.
