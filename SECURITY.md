# Security

This is a development prototype and is not ready for sensitive real group use or emergency coordination. Native security integrations and private messaging have not completed review.

Do not put precise locations, message content, keys or exploitable details into a public issue. Use [GitHub private vulnerability reporting](https://github.com/fabiogiacomini/Vico/security/advisories/new). Private reporting is enabled and its API configuration has been verified. Include the minimum evidence needed; do not send real outing histories or unnecessary personal data.

Release gates include a reviewed threat model, audited protocol integration, verified native storage and backup behavior, deletion/replay tests, data inventory, dependency/license review and an independent security assessment. See `docs/threat-model.md` and `docs/deletion.md`.
