# Vico 0.1.0 — Android preview 1

Early Android preview for trying local outing workflows. This is development software, with limited features and no completed physical-device field or security audit.

## Download and install

Download **Vico-0.1.0-preview.1-android.apk** from the release assets on an ARM64 Android phone running Android 8 or later. No Expo Go or computer connection is required after installation. x86_64 is also included; 32-bit devices are not supported by this preview.

The APK uses the owner's dedicated release certificate. `SHA256SUMS` identifies the downloaded file; the public signing certificate fingerprint is provided alongside it. Private signing material is not published.

## Available

- English interface; local outing creation and expiry.
- GPX import with preserved segment gaps, route geometry and meeting points.
- Foreground positioning with explicit permission and visible accuracy.
- Encrypted on-device storage and permanent local outing deletion.
- Optional area weather forecasts after opt-in.
- Honest missing crowd-data states and candidate source details.

## Not connected yet

Private group chat, invitations, live sharing, background positioning, downloadable basemaps, online walking routing and active crowd feeds are not available. The default route view is a labelled geometry diagram, not a detailed basemap. The practice route is synthetic and must not be used as a real trail.

This preview is not emergency or rescue software. Keep established navigation and communication tools available during real outings.

## Validation

Passed: strict TypeScript, 60 domain/lifecycle tests, native release compilation, signature/payload verification and the API 35 x86_64 emulator smoke test. Startup, synthetic outing creation, encrypted persistence after restart, local deletion and absence after another restart were exercised. The tested copy used a disposable CI certificate; the published APK has the same application payload with the owner's release signature. Physical Android phones and the iOS Personal Team test remain pending. Full group encryption and an independent security review remain future release gates.
